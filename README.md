# 🎹 JS Web Audio Piano

An interactive, responsive 8-key browser piano built with HTML5, Tailwind CSS, and modern JavaScript using the native **Web Audio API**. No external sound samples or audio files required—all tones are synthesized directly in real time.

---

## ✨ Features

- **8-Key Scale (Do-Re-Mi)**: Play notes from C4 ($Do$) to C5 ($Do'$) mapped with precise frequencies.
- **Synthesized Audio**: Procedural sound generation powered by the Web Audio API with natural decay envelopes.
- **Multiple Instrument Timbres**: Toggle on-the-fly between Warm Piano, Soft Flute, 8-Bit Arcade, and Bright Brass.
- **Dual Keyboard Controls**: Play notes effortlessly using computer keyboard shortcuts:
  - Numbers: `1` to `8`
  - Home Row Letters: `A`, `S`, `D`, `F`, `G`, `H`, `J`, `K`
- **Interactive Practice Mode**: Follow interactive visual guides to play classic melodies (*Twinkle Twinkle Little Star*, *Mary Had a Little Lamb*, and *Jingle Bells*).

---

## 🛠️ Built With

- **HTML5** – UI Structure
- **Tailwind CSS** – Styling and layout
- **JavaScript (ES6+)** – Logic & Event Handling
- **Web Audio API** – Real-time audio synthesis
