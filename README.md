# 🎹 JS Web Audio Piano

An interactive, responsive 8-key browser piano built with HTML5, Tailwind CSS, and modern JavaScript using the native **Web Audio API**. No external audio samples are required—all tones are synthesized directly in real time.

---
📱 **Mobile Responsive**: Fully optimized for mobile web browsers with touch-screen controls for iOS and Android devices!
---

## ✨ Features

- **8-Key Solfège Scale**: Play a full major octave from **Do** (C4) to **Do'** (C5) tuned to precise mathematical frequencies.
- **Real-Time Sound Synthesis**: Powered by the Web Audio API with natural decay envelopes.
- **Multiple Instrument Timbres**: Toggle on-the-fly between Warm Piano, Soft Flute, 8-Bit Arcade, and Bright Brass.
- **Dual Keyboard Controls**: Play notes using your computer keyboard:
  - Numbers: `1` through `8`
  - Home Row Letters: `A`, `S`, `D`, `F`, `G`, `H`, `J`, `K`
- **Interactive Practice Songs**: Visual guide modes for classic tunes (*Twinkle Twinkle Little Star*, *Mary Had a Little Lamb*, and *Jingle Bells*).

---

## 🎼 What is Solfège?

**Solfège** (or *solfeggio*) is a music education method used to teach pitch recognition and sight-singing. By assigning a distinct syllable (**Do, Re, Mi, Fa, So, La, Ti, Do**) to each scale degree, singers can build strong pitch memory and relative pitch awareness.

---

## 🎙️ Vocal Practice & Ear Training Guide

This web piano doubles as a simple tool for vocal warm-ups and pitch training:

1. **Vocal Warm-Ups**: Click or key through the scale sequentially ($Do \rightarrow Re \rightarrow Mi \dots$) and sing each syllable aloud, matching your voice to the synthetic reference pitch.
2. **Key & Pitch Reference**: Tap out starting notes or key references before singing a cover or vocal track.
3. **Interval Training**: Play jump intervals (e.g., $Do \rightarrow Mi$ or $Do \rightarrow So$) to test and train your relative pitch accuracy.
4. **Keyboard & Finger Dexterity**: Practice QWERTY home-row finger movement (`A`-`K`) alongside musical timing.
